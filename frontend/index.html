How generation stays governed

deterministic — the spec renders identically every time; no hidden model calls. AI content enters via the spec and was already ledgered (§20).

provenance footer — every artefact carries CAIOS, UTC time and a verify-before-external-use note.

event trail — created → generating → ready (or failed, with the honest reason) on an append-only log.

private storage — bytes sit server-side; downloads stream through the authorised API, never public URLs.

QA gate — only QA-approved artefacts are releasable; revisions reset the gate, and approval never carries over.

injection guard — spreadsheet cells that start like formulas are stored as text, never executed.

prompt version — the template that produced this answer is pinned in the response.
